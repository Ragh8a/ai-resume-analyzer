# AI Resume Analyzer & Job Matcher

AI-powered platform for analyzing resumes, matching candidates with jobs,
providing career recommendations, and improving resumes using AI.

## Features

- Resume analysis
- PDF and DOCX extraction
- Technical skills extraction
- Soft skills extraction
- Education extraction
- Experience extraction
- AI-based job matching
- Missing skills detection
- Career recommendations
- Resume improvement suggestions
- Job creation
- Job search
- User authentication
- SQLite database
- RAG-based career advisor

## Technologies

- Python
- FastAPI
- SQLite
- Groq API
- HTML
- CSS
- JavaScript
- Jinja2
- PDF/DOCX processing
